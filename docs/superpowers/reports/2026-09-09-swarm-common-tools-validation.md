CLI and MCP integration can now share one closed decoder and static catalog for nine peer operations: identity, peer listing, mailbox, thread and outgoing reads, send, acknowledge, status and attachment resolution. Inputs reject unknown authority fields, malformed or duplicate JSON keys, invalid page sizes and oversized arguments. Exact navigation integers and caller-selected idempotency keys are preserved. The broker remains responsible for identity, permissions and domain validation; this checkpoint does not add the native helper executable or install collaboration into TermX.

A regression serializes an actual core OutgoingPage with ten messages and 4096 recipients each. Its 8,031,440 bytes fit the existing 8 MiB page bound, but its 614,671 work nodes exceeded the JSON validator's previous 524,288-node limit. Raising only that cap to 1,048,576 makes the typed round-trip pass without changing fixed scanner storage. Earlier synthetic metadata fixtures did not reveal this valid recipient-heavy case.
