# TermX Milestone 1 — Host Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `termx-host.exe` — the Rust session daemon that owns ConPTY shell sessions, serves them over an authenticated localhost WebSocket, keeps a hard-capped ring-buffer scrollback, and lets a client disconnect/reconnect with full replay (the "kill-UI-survive" property).

**Architecture:** Single Rust binary. A tokio WebSocket server (JSON control messages + binary I/O frames) fronts a session registry; each session runs a ConPTY child via `portable-pty` with a blocking reader thread feeding a byte ring buffer and a tokio broadcast channel. State (session metadata + an opaque UI layout blob) persists to `state.json` debounced. All filesystem locations resolve at runtime — `%APPDATA%\TermX` or `<exe dir>\data` in portable mode, `--data-dir` override for tests.

**Tech Stack:** Rust 2021, tokio 1, tokio-tungstenite 0.24 (pinned), portable-pty 0.9, serde/serde_json 1, tracing + tracing-appender, anyhow/thiserror, rand 0.8, base64 0.22.

## Global Constraints

- **Portability (global CLAUDE.md):** zero hardcoded absolute paths in source; every path derives from `std::env::current_exe()`, environment variables read at runtime, or the `--data-dir` CLI override. `portable.flag` beside the exe switches storage to `<exe dir>\data`.
- **Memory bounded by design:** ring buffer default cap 4 MiB/session (`scrollback_bytes` in config.json; the 10,000-line display scrollback from the spec is a UI-side xterm.js setting in M2). Broadcast channels are bounded; a lagging consumer gets a `Lagged` signal and resyncs via replay — never unbounded buffering.
- **Sessions outlive clients:** no client-connection state may own a session. Dropping every WebSocket must leave sessions running.
- Windows-first: tests run on Windows; shells resolved via `%SystemRoot%`/`%ComSpec%` env vars at runtime.
- Workspace root is `C:\Dev\TermX` (all paths below relative to it). Run commands from the repo root in PowerShell.

```rust
/// Resolution order: explicit override -> portable.flag beside the exe -> %APPDATA%\TermX.
/// Creates the directory (and parents) before returning it.
pub fn resolve_data_dir(override_dir: Option<&Path>) -> Result<PathBuf> {
    let dir = if let Some(d) = override_dir {
        d.to_path_buf()
    } else if let Some(portable) = portable_data_dir() {
        portable
    } else {
        let appdata = std::env::var("APPDATA").context("APPDATA not set")?;
        PathBuf::from(appdata).join("TermX")
    };
    std::fs::create_dir_all(&dir)
        .with_context(|| format!("creating data dir {}", dir.display()))?;
    Ok(dir)
}

/// Some(<exe dir>/data) iff a `portable.flag` file sits beside the running exe.
fn portable_data_dir() -> Option<PathBuf> {
    let exe = std::env::current_exe().ok()?;
    let dir = exe.parent()?;
    if dir.join("portable.flag").is_file() {
        Some(dir.join("data"))
    } else {
        None
    }
}

pub fn runtime_file(data_dir: &Path) -> PathBuf {
    data_dir.join("runtime.json")
}

pub fn logs_dir(data_dir: &Path) -> PathBuf {
    data_dir.join("logs")
}
```

```rust
    #[serde(default = "default_scrollback_bytes")]
    pub scrollback_bytes: usize,
    #[serde(default = "default_profile")]
    pub default_profile: String,
}

    fn default() -> Self {
        Self {
            scrollback_bytes: default_scrollback_bytes(),
            default_profile: default_profile(),
        }
    }

/// Load <data>/config.json, creating it with defaults if absent.
/// A malformed file is a hard error — we never silently overwrite user edits.
pub fn load_or_create(data_dir: &Path) -> Result<Config> {
    let path = data_dir.join("config.json");
    if path.is_file() {
        let text = std::fs::read_to_string(&path)
            .with_context(|| format!("reading {}", path.display()))?;
        let cfg: Config = serde_json::from_str(&text)
            .with_context(|| format!("parsing {} — fix or delete it", path.display()))?;
        Ok(cfg)
    } else {
        let cfg = Config::default();
        std::fs::write(&path, serde_json::to_string_pretty(&cfg)?)
            .with_context(|| format!("writing {}", path.display()))?;
        Ok(cfg)
    }
}
```

```rust
pub struct RingBuffer {
    buf: VecDeque<u8>,
    cap: usize,
    total_written: u64,
}

impl RingBuffer {
    pub fn new(cap: usize) -> Self {
        assert!(cap > 0, "ring cap must be positive");
        Self { buf: VecDeque::with_capacity(cap.min(64 * 1024)), cap, total_written: 0 }
    }

    pub fn push(&mut self, data: &[u8]) {
        self.total_written += data.len() as u64;
        // Only the last `cap` bytes of `data` can survive; skip the rest cheaply.
        let keep = if data.len() > self.cap { &data[data.len() - self.cap..] } else { data };
        let overflow = (self.buf.len() + keep.len()).saturating_sub(self.cap);
        self.buf.drain(..overflow);
        self.buf.extend(keep);
    }

    pub fn snapshot(&self) -> (u64, Vec<u8>) {
        let start = self.total_written - self.buf.len() as u64;
        (start, self.buf.iter().copied().collect())
    }

    pub fn end_offset(&self) -> u64 {
        self.total_written
    }

    pub fn len(&self) -> usize {
        self.buf.len()
    }

    pub fn is_empty(&self) -> bool {
        self.buf.is_empty()
    }
}
```

```rust
    Output { session_id: SessionId, offset: u64, data: Vec<u8> },
    Input { session_id: SessionId, data: Vec<u8> },
}

const TAG_OUTPUT: u8 = 1;
const TAG_INPUT: u8 = 2;

pub fn encode_frame(f: &Frame) -> Vec<u8> {
    match f {
        Frame::Output { session_id, offset, data } => {
            let mut buf = Vec::with_capacity(13 + data.len());
            buf.push(TAG_OUTPUT);
            buf.extend_from_slice(&session_id.to_le_bytes());
            buf.extend_from_slice(&offset.to_le_bytes());
            buf.extend_from_slice(data);
            buf
        }
        Frame::Input { session_id, data } => {
            let mut buf = Vec::with_capacity(5 + data.len());
            buf.push(TAG_INPUT);
            buf.extend_from_slice(&session_id.to_le_bytes());
            buf.extend_from_slice(data);
            buf
        }
    }
}

pub fn decode_frame(buf: &[u8]) -> Result<Frame> {
    if buf.is_empty() {
        bail!("empty frame");
    }
    match buf[0] {
        TAG_OUTPUT => {
            if buf.len() < 13 {
                bail!("output frame too short: {} bytes", buf.len());
            }
            Ok(Frame::Output {
                session_id: u32::from_le_bytes(buf[1..5].try_into().unwrap()),
                offset: u64::from_le_bytes(buf[5..13].try_into().unwrap()),
                data: buf[13..].to_vec(),
            })
        }
        TAG_INPUT => {
            if buf.len() < 5 {
                bail!("input frame too short: {} bytes", buf.len());
            }
            Ok(Frame::Input {
                session_id: u32::from_le_bytes(buf[1..5].try_into().unwrap()),
                data: buf[5..].to_vec(),
            })
        }
        tag => bail!("unknown frame tag {tag}"),
    }
}
```

```rust
#[derive(Clone, Debug)]
pub struct OutputChunk {
    pub offset: u64,
    pub data: Arc<Vec<u8>>,
}

enum WriterCmd {
    Data(Vec<u8>),
}

pub struct Session {
    ring: Arc<Mutex<RingBuffer>>,
    tx_out: broadcast::Sender<OutputChunk>,
    tx_writer: std::sync::mpsc::Sender<WriterCmd>,
    master: Mutex<Box<dyn portable_pty::MasterPty + Send>>,
    killer: Mutex<Box<dyn ChildKiller + Send + Sync>>,
    exit: Arc<Mutex<Option<Option<u32>>>>,
}

impl Session {
    pub fn spawn(
        profile: &Profile,
        cwd: Option<&Path>,
        cols: u16,
        rows: u16,
        ring_cap: usize,
    ) -> Result<Session> {
        let pty = native_pty_system();
        let pair = pty
            .openpty(PtySize { rows, cols, pixel_width: 0, pixel_height: 0 })
            .context("openpty")?;

        let mut cmd = CommandBuilder::new(profile.command.as_os_str());
        cmd.args(profile.args.iter());
        if let Some(dir) = cwd {
            cmd.cwd(dir);
        }
        let mut child = pair.slave.spawn_command(cmd).context("spawn shell")?;
        let killer = child.clone_killer();
        drop(pair.slave); // required: keeps EOF semantics correct on child exit

        let mut reader = pair.master.try_clone_reader().context("clone reader")?;
        let mut writer = pair.master.take_writer().context("take writer")?;

        let ring = Arc::new(Mutex::new(RingBuffer::new(ring_cap)));
        let (tx_out, _) = broadcast::channel::<OutputChunk>(256);
        let exit: Arc<Mutex<Option<Option<u32>>>> = Arc::new(Mutex::new(None));

        // Writer thread: serializes all input to the PTY.
        let (tx_writer, rx_writer) = std::sync::mpsc::channel::<WriterCmd>();
        std::thread::spawn(move || {
            while let Ok(WriterCmd::Data(data)) = rx_writer.recv() {
                if writer.write_all(&data).is_err() {
                    break; // PTY gone; child exited
                }
                let _ = writer.flush();
            }
        });

        // Reader thread: sole producer into ring + broadcast.
        let ring_r = Arc::clone(&ring);
        let tx_r = tx_out.clone();
        std::thread::spawn(move || {
            let mut buf = [0u8; 8192];
            loop {
                match reader.read(&mut buf) {
                    Ok(0) | Err(_) => break, // EOF: child exited
                    Ok(n) => {
                        let mut ring = ring_r.lock().unwrap();
                        let offset = ring.end_offset();
                        ring.push(&buf[..n]);
                        drop(ring);
                        // Laggards get Lagged and resync via snapshot(); send() only
                        // errors when there are no receivers, which is fine.
                        let _ = tx_r.send(OutputChunk {
                            offset,
                            data: Arc::new(buf[..n].to_vec()),
                        });
                    }
                }
            }
        });

        // Waiter thread: records the exit code once.
        let exit_w = Arc::clone(&exit);
        std::thread::spawn(move || {
            let code = child.wait().ok().map(|status| status.exit_code());
            *exit_w.lock().unwrap() = Some(code);
        });

        Ok(Session {
            ring,
            tx_out,
            tx_writer,
            master: Mutex::new(pair.master),
            killer: Mutex::new(killer),
            exit,
        })
    }

    pub fn write_input(&self, data: &[u8]) -> Result<()> {
        self.tx_writer
            .send(WriterCmd::Data(data.to_vec()))
            .context("session writer thread gone")
    }

    pub fn resize(&self, cols: u16, rows: u16) -> Result<()> {
        self.master
            .lock()
            .unwrap()
            .resize(PtySize { rows, cols, pixel_width: 0, pixel_height: 0 })
            .context("pty resize")
    }

    pub fn subscribe(&self) -> broadcast::Receiver<OutputChunk> {
        self.tx_out.subscribe()
    }

    pub fn snapshot(&self) -> (u64, Vec<u8>) {
        self.ring.lock().unwrap().snapshot()
    }

    pub fn kill(&self) {
        let _ = self.killer.lock().unwrap().kill();
    }

    pub fn exited(&self) -> Option<Option<u32>> {
        *self.exit.lock().unwrap()
    }

    pub fn wait_exit_blocking(&self, timeout: Duration) -> bool {
        let deadline = std::time::Instant::now() + timeout;
        while std::time::Instant::now() < deadline {
            if self.exited().is_some() {
                return true;
            }
            std::thread::sleep(Duration::from_millis(50));
        }
        false
    }
}
```

```rust
    info: SessionInfo,
}

pub struct Registry {
    data_dir: PathBuf,
    config: Config,
    next_id: AtomicU32,
    entries: Mutex<HashMap<SessionId, Entry>>,
    layout: Mutex<serde_json::Value>,
}

impl Registry {
    pub fn new(data_dir: PathBuf, config: Config) -> Registry {
        let layout = std::fs::read_to_string(data_dir.join("state.json"))
            .ok()
            .and_then(|text| serde_json::from_str::<serde_json::Value>(&text).ok())
            .map(|v| v.get("layout").cloned().unwrap_or(serde_json::Value::Null))
            .unwrap_or(serde_json::Value::Null);
        Registry {
            data_dir,
            config,
            next_id: AtomicU32::new(1),
            entries: Mutex::new(HashMap::new()),
            layout: Mutex::new(layout),
        }
    }

    pub fn create_session(
        &self,
        profile: Option<&str>,
        cwd: Option<&Path>,
        cols: u16,
        rows: u16,
    ) -> Result<(SessionInfo, Arc<Session>)> {
        let name = profile.unwrap_or(&self.config.default_profile);
        let prof = profiles::resolve(name)?;
        let session = Arc::new(Session::spawn(
            &prof,
            cwd,
            cols,
            rows,
            self.config.scrollback_bytes,
        )?);
        let id = self.next_id.fetch_add(1, Ordering::SeqCst);
        let info = SessionInfo {
            id,
            profile: name.to_string(),
            cwd: cwd.map(|p| p.display().to_string()),
            cols,
            rows,
            alive: true,
        };
        self.entries.lock().unwrap().insert(
            id,
            Entry { session: Arc::clone(&session), info: info.clone() },
        );
        let _ = self.persist();
        Ok((info, session))
    }

    pub fn get(&self, id: SessionId) -> Option<Arc<Session>> {
        self.entries.lock().unwrap().get(&id).map(|e| Arc::clone(&e.session))
    }

    pub fn close_session(&self, id: SessionId) -> bool {
        let removed = self.entries.lock().unwrap().remove(&id);
        match removed {
            Some(entry) => {
                entry.session.kill();
                let _ = self.persist();
                true
            }
            None => false,
        }
    }

    pub fn list(&self) -> Vec<SessionInfo> {
        let mut infos: Vec<SessionInfo> = self
            .entries
            .lock()
            .unwrap()
            .values()
            .map(|e| {
                let mut info = e.info.clone();
                info.alive = e.session.exited().is_none();
                info
            })
            .collect();
        infos.sort_by_key(|i| i.id);
        infos
    }

    pub fn set_layout(&self, layout: serde_json::Value) {
        *self.layout.lock().unwrap() = layout;
        let _ = self.persist();
    }

    pub fn layout(&self) -> serde_json::Value {
        self.layout.lock().unwrap().clone()
    }

    /// Atomic write: tmp file + rename, so a crash mid-write never corrupts state.
    pub fn persist(&self) -> Result<()> {
        let state = serde_json::json!({
            "layout": self.layout(),
            "sessions": self.list(),
        });
        let path = self.data_dir.join("state.json");
        let tmp = self.data_dir.join("state.json.tmp");
        std::fs::write(&tmp, serde_json::to_string_pretty(&state)?)
            .with_context(|| format!("writing {}", tmp.display()))?;
        std::fs::rename(&tmp, &path).with_context(|| format!("renaming to {}", path.display()))?;
        Ok(())
    }

    pub fn shutdown_all(&self) {
        for (_, entry) in self.entries.lock().unwrap().drain() {
            entry.session.kill();
        }
    }
}
```

```rust
#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct RuntimeInfo {
    pub port: u16,
    pub token: String,
    pub pid: u32,
    pub version: String,
}

pub async fn run(
    registry: Arc<Registry>,
    data_dir: PathBuf,
    shutdown: tokio::sync::watch::Sender<bool>,
    ready: tokio::sync::oneshot::Sender<RuntimeInfo>,
) -> Result<()> {
    let listener = TcpListener::bind(("127.0.0.1", 0)).await.context("bind")?;
    let port = listener.local_addr()?.port();
    let token: String = {
        use rand::Rng;
        let mut rng = rand::thread_rng();
        (0..32).map(|_| format!("{:x}", rng.gen_range(0..16u8))).collect()
    };
    let info = RuntimeInfo {
        port,
        token: token.clone(),
        pid: std::process::id(),
        version: env!("CARGO_PKG_VERSION").to_string(),
    };
    let runtime_path = crate::paths::runtime_file(&data_dir);
    std::fs::write(&runtime_path, serde_json::to_string_pretty(&info)?)
        .with_context(|| format!("writing {}", runtime_path.display()))?;
    let _ = ready.send(info);

    let mut shutdown_rx = shutdown.subscribe();
    loop {
        tokio::select! {
            accepted = listener.accept() => {
                let (stream, _addr) = accepted.context("accept")?;
                let reg = Arc::clone(&registry);
                let tok = token.clone();
                let sd = shutdown.clone();
                tokio::spawn(async move {
                    if let Err(e) = handle_conn(stream, reg, tok, sd).await {
                        tracing::debug!("connection ended: {e:#}");
                    }
                });
            }
            _ = shutdown_rx.changed() => {
                if *shutdown_rx.borrow() {
                    let _ = std::fs::remove_file(&runtime_path);
                    tracing::info!("shutdown requested; exiting accept loop");
                    return Ok(());
                }
            }
        }
    }
}

async fn handle_conn(
    stream: TcpStream,
    registry: Arc<Registry>,
    token: String,
    shutdown: tokio::sync::watch::Sender<bool>,
) -> Result<()> {
    let ws = tokio_tungstenite::accept_async(stream).await.context("ws accept")?;
    let (mut tx, mut rx) = ws.split();

    // ---- Auth gate: first message, 5s budget ----
    let first = tokio::time::timeout(std::time::Duration::from_secs(5), rx.next())
        .await
        .ok()
        .flatten()
        .transpose()
        .ok()
        .flatten();
    let authed = matches!(
        first.as_ref().and_then(|m| m.to_text().ok())
            .and_then(|t| serde_json::from_str::<ClientMsg>(t).ok()),
        Some(ClientMsg::Auth { token: ref t }) if *t == token
    );
    if !authed {
        let _ = tx
            .send(Message::Text(serde_json::to_string(&HostMsg::AuthErr {
                reason: "bad or missing token".into(),
            })?))
            .await;
        return Ok(());
    }
    tx.send(Message::Text(serde_json::to_string(&HostMsg::AuthOk {
        version: env!("CARGO_PKG_VERSION").to_string(),
        sessions: registry.list(),
    })?))
    .await?;

    // ---- Post-auth: fan session output into one outbound channel ----
    // Outbound is bounded; a wedged socket eventually drops chunks for THIS
    // client only (ring stays authoritative; client resyncs via replay).
    let (out_tx, mut out_rx) = tokio::sync::mpsc::channel::<Message>(1024);

    // Writer half: single task owns `tx`.
    let writer = tokio::spawn(async move {
        while let Some(msg) = out_rx.recv().await {
            if tx.send(msg).await.is_err() {
                break;
            }
        }
    });

    // Per-attached-session forwarder tasks, aborted on Detach/socket end.
    let mut forwarders: std::collections::HashMap<SessionId, tokio::task::JoinHandle<()>> =
        std::collections::HashMap::new();

    while let Some(msg) = rx.next().await {
        let msg = match msg {
            Ok(m) => m,
            Err(_) => break,
        };
        match msg {
            Message::Text(text) => {
                let parsed: ClientMsg = match serde_json::from_str(&text) {
                    Ok(p) => p,
                    Err(e) => {
                        let _ = out_tx
                            .send(Message::Text(serde_json::to_string(&HostMsg::Error {
                                context: "parse".into(),
                                message: e.to_string(),
                            })?))
                            .await;
                        continue;
                    }
                };
                match parsed {
                    ClientMsg::Auth { .. } => {} // already authed; ignore
                    ClientMsg::CreateSession { profile, cwd, cols, rows } => {
                        let result = registry.create_session(
                            profile.as_deref(),
                            cwd.as_deref().map(std::path::Path::new),
                            cols,
                            rows,
                        );
                        let reply = match result {
                            Ok((info, _)) => HostMsg::SessionCreated { info },
                            Err(e) => HostMsg::Error {
                                context: "create_session".into(),
                                message: format!("{e:#}"),
                            },
                        };
                        let _ = out_tx.send(Message::Text(serde_json::to_string(&reply)?)).await;
                    }
                    ClientMsg::Attach { session_id, replay } => {
                        let Some(session) = registry.get(session_id) else {
                            let _ = out_tx
                                .send(Message::Text(serde_json::to_string(&HostMsg::Error {
                                    context: "attach".into(),
                                    message: format!("no session {session_id}"),
                                })?))
                                .await;
                            continue;
                        };
                        // Subscribe FIRST, then snapshot: no gap between replay and live.
                        let mut chunk_rx = session.subscribe();
                        let replay_end = if replay {
                            let (start_offset, bytes) = session.snapshot();
                            let end = start_offset + bytes.len() as u64;
                            let _ = out_tx
                                .send(Message::Text(serde_json::to_string(&HostMsg::Replay {
                                    session_id,
                                    start_offset,
                                    data_b64: base64::engine::general_purpose::STANDARD
                                        .encode(&bytes),
                                })?))
                                .await;
                            end
                        } else {
                            // Live-only attach still needs a horizon: everything
                            // already in the ring is "the past" for this client.
                            let (start_offset, bytes) = session.snapshot();
                            start_offset + bytes.len() as u64
                        };
                        let fwd_out = out_tx.clone();
                        let session_for_fwd = Arc::clone(&session);
                        let handle = tokio::spawn(async move {
                            loop {
                                match chunk_rx.recv().await {
                                    Ok(chunk) => {
                                        let end = chunk.offset + chunk.data.len() as u64;
                                        if end <= replay_end {
                                            continue; // already covered by replay
                                        }
                                        let frame = protocol::encode_frame(&Frame::Output {
                                            session_id,
                                            offset: chunk.offset,
                                            data: chunk.data.to_vec(),
                                        });
                                        if fwd_out.send(Message::Binary(frame)).await.is_err() {
                                            break;
                                        }
                                    }
                                    Err(tokio::sync::broadcast::error::RecvError::Lagged(_)) => {
                                        // Bounded-memory path: resend authoritative ring.
                                        let (start_offset, bytes) = session_for_fwd.snapshot();
                                        let msg = HostMsg::Replay {
                                            session_id,
                                            start_offset,
                                            data_b64: base64::engine::general_purpose::STANDARD
                                                .encode(&bytes),
                                        };
                                        if let Ok(text) = serde_json::to_string(&msg) {
                                            if fwd_out.send(Message::Text(text)).await.is_err() {
                                                break;
                                            }
                                        }
                                    }
                                    Err(tokio::sync::broadcast::error::RecvError::Closed) => break,
                                }
                            }
                        });
                        if let Some(old) = forwarders.insert(session_id, handle) {
                            old.abort();
                        }
                    }
                    ClientMsg::Detach { session_id } => {
                        if let Some(handle) = forwarders.remove(&session_id) {
                            handle.abort();
                        }
                    }
                    ClientMsg::Resize { session_id, cols, rows } => {
                        if let Some(session) = registry.get(session_id) {
                            let _ = session.resize(cols, rows);
                        }
                    }
                    ClientMsg::CloseSession { session_id } => {
                        if let Some(handle) = forwarders.remove(&session_id) {
                            handle.abort();
                        }
                        registry.close_session(session_id);
                        let _ = out_tx
                            .send(Message::Text(serde_json::to_string(&HostMsg::SessionClosed {
                                session_id,
                            })?))
                            .await;
                    }
                    ClientMsg::ListSessions => {
                        let _ = out_tx
                            .send(Message::Text(serde_json::to_string(&HostMsg::Sessions {
                                sessions: registry.list(),
                            })?))
                            .await;
                    }
                    ClientMsg::SetLayout { layout } => {
                        registry.set_layout(layout);
                    }
                    ClientMsg::GetState => {
                        let _ = out_tx
                            .send(Message::Text(serde_json::to_string(&HostMsg::State {
                                layout: registry.layout(),
                                sessions: registry.list(),
                            })?))
                            .await;
                    }
                    ClientMsg::Shutdown => {
                        registry.shutdown_all();
                        let _ = shutdown.send(true);
                        break;
                    }
                }
            }
            Message::Binary(buf) => {
                if let Ok(Frame::Input { session_id, data }) = protocol::decode_frame(&buf) {
                    if let Some(session) = registry.get(session_id) {
                        let _ = session.write_input(&data);
                    }
                }
            }
            Message::Close(_) => break,
            _ => {}
        }
    }

    // Client gone: tear down THIS client's forwarders. Sessions keep running.
    for (_, handle) in forwarders.drain() {
        handle.abort();
    }
    writer.abort();
    Ok(())
}
```

```rust
fn main() -> Result<()> {
    let override_dir = parse_data_dir_arg();
    let data_dir = paths::resolve_data_dir(override_dir.as_deref())?;

    if let Some(info) = already_running(&data_dir) {
        println!("termx-host already running (pid {}, port {})", info.pid, info.port);
        return Ok(());
    }

    let logs = paths::logs_dir(&data_dir);
    std::fs::create_dir_all(&logs).context("creating logs dir")?;
    let file_appender = tracing_appender::rolling::daily(&logs, "host.log");
    let (file_writer, _guard) = tracing_appender::non_blocking(file_appender);
    use tracing_subscriber::layer::SubscriberExt;
    use tracing_subscriber::util::SubscriberInitExt;
    tracing_subscriber::registry()
        .with(tracing_subscriber::EnvFilter::try_from_default_env()
            .unwrap_or_else(|_| tracing_subscriber::EnvFilter::new("info")))
        .with(tracing_subscriber::fmt::layer().with_writer(std::io::stderr))
        .with(tracing_subscriber::fmt::layer().with_writer(file_writer).with_ansi(false))
        .init();

    let runtime = tokio::runtime::Runtime::new().context("tokio runtime")?;
    runtime.block_on(async {
        let reg = Arc::new(Registry::new(data_dir.clone(), cfg));
        let (shutdown_tx, mut shutdown_rx) = tokio::sync::watch::channel(false);
        let (ready_tx, ready_rx) = tokio::sync::oneshot::channel();
        let server_task = tokio::spawn(server::run(
            Arc::clone(&reg),
            data_dir.clone(),
            shutdown_tx,
            ready_tx,
        ));
        match ready_rx.await {
            Ok(info) => tracing::info!("listening on 127.0.0.1:{}", info.port),
            Err(_) => anyhow::bail!("server failed before ready"),
        }
        // Wait for shutdown-flag flip (server exits its accept loop itself).
        while !*shutdown_rx.borrow() {
            if shutdown_rx.changed().await.is_err() {
                break;
            }
        }
        let _ = server_task.await;
        tracing::info!("termx-host exiting cleanly");
        Ok(())
    })
}
```

```rust
//! Black-box test of the real binary: the M1 acceptance test.

use futures_util::{SinkExt, StreamExt};
use serde_json::Value;
use std::time::Duration;
use tokio_tungstenite::tungstenite::Message;

fn read_runtime(dir: &std::path::Path) -> Option<Value> {
    let text = std::fs::read_to_string(dir.join("runtime.json")).ok()?;
    serde_json::from_str(&text).ok()
}

async fn ws_connect(
    port: u64,
) -> tokio_tungstenite::WebSocketStream<
    tokio_tungstenite::MaybeTlsStream<tokio::net::TcpStream>,
> {
    let (ws, _) = tokio_tungstenite::connect_async(format!("ws://127.0.0.1:{port}"))
        .await
        .expect("ws connect");
    ws
}

async fn send(ws: &mut (impl SinkExt<Message, Error = tokio_tungstenite::tungstenite::Error> + Unpin), v: Value) {
    ws.send(Message::Text(v.to_string())).await.unwrap();
}

async fn next_control(
    ws: &mut (impl StreamExt<Item = Result<Message, tokio_tungstenite::tungstenite::Error>> + Unpin),
) -> Value {
    loop {
        let msg = tokio::time::timeout(Duration::from_secs(30), ws.next())
            .await
            .expect("timeout")
            .expect("stream end")
            .expect("ws err");
        if let Message::Text(t) = msg {
            return serde_json::from_str(&t).unwrap();
        }
    }
}

#[tokio::test]
async fn full_lifecycle_against_real_binary() {
    let tmp = tempfile::tempdir().unwrap();
    let exe = env!("CARGO_BIN_EXE_termx-host");
    let mut host = std::process::Command::new(exe)
        .args(["--data-dir", tmp.path().to_str().unwrap()])
        .spawn()
        .expect("spawn termx-host");

    // Wait for runtime.json (boot signal), up to 15s.
    let rt = {
        let deadline = std::time::Instant::now() + Duration::from_secs(15);
        loop {
            if let Some(v) = read_runtime(tmp.path()) {
                break v;
            }
            assert!(std::time::Instant::now() < deadline, "host never wrote runtime.json");
            tokio::time::sleep(Duration::from_millis(200)).await;
        }
    };
    let port = rt["port"].as_u64().unwrap();
    let token = rt["token"].as_str().unwrap().to_string();

    // Client A: create session, write marker, die abruptly.
    let session_id = {
        let mut ws = ws_connect(port).await;
        send(&mut ws, serde_json::json!({"type": "auth", "token": token})).await;
        let auth = next_control(&mut ws).await;
        assert_eq!(auth["type"], "auth_ok", "auth reply: {auth}");
        send(
            &mut ws,
            serde_json::json!({"type": "create_session", "profile": "cmd", "cwd": null, "cols": 100, "rows": 30}),
        )
        .await;
        let created = next_control(&mut ws).await;
        assert_eq!(created["type"], "session_created", "{created}");
        let id = created["info"]["id"].as_u64().unwrap();
        // Binary input frame: tag 2 + u32 id + payload.
        let mut frame = vec![2u8];
        frame.extend_from_slice(&(id as u32).to_le_bytes());
        frame.extend_from_slice(b"echo e2e_marker_7\r\n");
        ws.send(Message::Binary(frame)).await.unwrap();
        tokio::time::sleep(Duration::from_secs(3)).await;
        id
        // dropped without close — simulated UI crash
    };

    // Client B: reattach with replay; the marker must be there.
    let mut ws = ws_connect(port).await;
    send(&mut ws, serde_json::json!({"type": "auth", "token": token})).await;
    let auth = next_control(&mut ws).await;
    assert_eq!(auth["type"], "auth_ok");
    assert!(
        auth["sessions"].as_array().unwrap().iter().any(|s| s["id"].as_u64() == Some(session_id) && s["alive"] == true),
        "session gone after client death: {auth}"
    );
    send(&mut ws, serde_json::json!({"type": "attach", "session_id": session_id, "replay": true})).await;
    let replay = loop {
        let v = next_control(&mut ws).await;
        if v["type"] == "replay" {
            break v;
        }
    };
    let bytes = {
        use base64::Engine;
        base64::engine::general_purpose::STANDARD
            .decode(replay["data_b64"].as_str().unwrap())
            .unwrap()
    };
    assert!(
        String::from_utf8_lossy(&bytes).contains("e2e_marker_7"),
        "replay missing marker"
    );

    // Clean shutdown: host must exit and remove runtime.json.
    send(&mut ws, serde_json::json!({"type": "shutdown"})).await;
    let deadline = std::time::Instant::now() + Duration::from_secs(15);
    loop {
        match host.try_wait().unwrap() {
            Some(status) => {
                assert!(status.success(), "host exit status: {status:?}");
                break;
            }
            None => {
                assert!(std::time::Instant::now() < deadline, "host did not exit on Shutdown");
                tokio::time::sleep(Duration::from_millis(200)).await;
            }
        }
    }
    assert!(!tmp.path().join("runtime.json").exists(), "runtime.json must be cleaned up");
}
```

```markdown
# TermX

A stable, Warp-like terminal manager for Windows. Sessions live in a tiny Rust
daemon (`termx-host`) and survive UI crashes; the UI (Tauri, Milestone 2) is
disposable by design.

## Status

- [x] M1 — host core: ConPTY sessions, authenticated localhost WebSocket,
      capped ring-buffer scrollback, reattach-with-replay, state persistence
- [ ] M2 — UI shell: window, xterm.js, sidebar tabs/groups/colors
- [ ] M3 — folder picker | M4 — blocks + Ctrl+F | M5 — clickables
- [ ] M6 — split panes | M7 — palette/history/snippets | M8 — polish

Design spec: `docs/superpowers/specs/2026-07-17-termx-design.md`
Plans: `docs/superpowers/plans/`

## Dev

Requires Rust (stable, MSVC toolchain). From the repo root:

    cargo test -p termx-host          # full host suite (spawns real shells)
    cargo build -p termx-host         # target/debug/termx-host.exe

Run the host manually:

    cargo run -p termx-host           # data dir: %APPDATA%\TermX
    cargo run -p termx-host -- --data-dir X:\some\dir

`runtime.json` in the data dir has the port + auth token. A `portable.flag`
file beside the exe switches all storage to `<exe dir>\data`.

## Portability

No absolute paths in source or config — the app folder can move between
machines. Storage: `%APPDATA%\TermX` (default) or `<exe dir>\data` (portable
mode) or `--data-dir <path>` (explicit).
```
